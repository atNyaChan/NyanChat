# Nyanw 版本改动记录

## Agent 协作约定
- `AGENTS.md` 要求 Agent 在每次代码、资源或配置修改后同步维护本文件。
- 编辑本文件前先从头到尾阅读一次，不要只是往最后添加信息，也不要只使用 grep 简略阅读。
- 修改完成后要静态检查本次改动涉及的未引用组件，并删除未引用的翻译资源字符串，并使得各翻译资源与英文源文件同步。
- 禁止 Agent 自行执行编译、构建、测试或 Lint；相关验证由维护者手动完成。

## 聊天与消息
### 词数及生成统计（开启“显示 Token 和上下文统计”时）
- 相邻 ASCII 英文字母合计为一个词；其他 ASCII 符号、空格、CJK 字符和 emoji 等每个 Unicode 码点各计一个词。
- 用户消息的操作按钮行左侧显示词数。
- 流式回复期间每 100ms 更新词数（包含正文和思考过程）、已用时间、词/秒及生成中的思考词数。
- 生成完成后助手统计变为两行：第一行显示词数、时间、词/秒，第二行显示输入（缓存 token）、输出、token/秒（及费用（如果设置了模型单价））。
- 消息用时不足 150ms 时不显示 `word/s` 和 `tok/s`，避免展示失真的瞬时速度。
- 点击统计只切换精确数字和 `12.3K` 一类的缩写；仅数量超过 `10000` 时才采用缩写，并且无论数量多大都只使用 `K`。
- 模型 id 为空的助手消息（即为手动编辑的消息）只显示词数，并标注` (edited)`。
- 手动编辑的消息中的思考块只显示“思考”，自然生成且带有用量信息的零耗时思考仍显示“思考了 0.0 秒”。

- 输入框加号左侧分两行显示{当前输入词数、下一次请求总词数（不计思考内容）}、{附件与可供模型使用的工具数量}；第二行按实际存在的项目显示文件、工具图标及数量，两行右对齐并整体垂直居中。
- 输入框中的可解析文本文件会在附件框外侧右边显示文件正文词数，计入下一次请求总词数，不计入附件数；当前输入词数只统计直接输入的文本，不重复计算附件词数。
- 输入框获得焦点时构建并缓存系统提示、记忆、工具提示及转换后的既有历史消息；显示的总词数直接为缓存上下文词数加当前草稿词数。
- 用户消息中的可解析文本文件左侧显示灰色文件正文词数；只统计解析出的正文，不包含文件名及请求转换时加入的上传文件标签或包装文字。
- 键盘未弹出且没有草稿或附件时隐藏统计。
- 统计数值沿用消息统计的 `K` 缩写规则；关闭“显示 Token 和上下文统计”设置时不显示也不计算。

### 思考块
- 编辑助手消息时，将 `Reasoning` 内容重新插入输入框并表示为 `<think>...</think>`。
- 保存编辑后的助手消息时，将 `<think>` 标签重新解析为独立思考块。支持一条编辑文本中出现多个 `<think>` 块。
- 思考完成并展开思考块后，顶部右侧显示思考词数和复制按钮（点击即可复制思考 Markdown 原文）。
- 展开或收起思考与工具步骤时，标题行的按压反馈左右各保留 4dp 空白。

### 空白消息
- 允许发送仅包含空格等空白字符的消息。
- 同步调整了输入校验、消息 UI 判断及发送给模型前的消息过滤。
- 真正的空字符串仍不能作为单独消息发送。
- 纯空白用户消息使用不可见占位符维持正常气泡行高；该占位符仅用于显示，不改变保存或发送的原始内容。

### 模型价格
- 每个提供商的每个模型均可选中“设置价格”。
- 支持填写输入、输出、缓存读取、缓存写入价格，单位为美元/百万 token（输入/输出一行、缓存读取/写入一行）。
- 价格设置默认关闭，旧模型数据因字段具有默认值而保持兼容。
- 未出现缓存读取时，费用计算为 `输入价格 × 输入 token + 输出价格 × 输出 token`。
- 出现缓存读取时，不使用普通输入价格，费用计算为：
	```text
	缓存写入价格 ×（输入 token - 缓存读取 token）
	+ 缓存读取价格 × 缓存读取 token
	+ 输出价格 × 输出 token
	```

### 侧栏
#### 搜索消息
- 搜索聊天页共有“仅匹配标题”、“精准匹配”、“模糊搜索”、“按照模型…”、“按照附件…”五种模式；默认使用精准匹配并记住用户选择（只有前三种可以被用作默认值）。精准匹配使用区分大小写的连续字符串包含判断；模糊搜索按空格拆分关键词，要求各段在消息中依次且全部出现，例如 `你 好` 可匹配“你真好”，`s r h` 可匹配 `search`。仅模糊搜索允许按相关性排序，其他搜索模式及模型筛选会自动改为从新到旧，新安装默认从新到旧。
- 模糊搜索选择并高亮消息中 各空格分段按顺序出现且间隔字符总数最少的一组完整匹配；按相关性排序时优先显示总间隔更少的结果，相同则按消息时间从新到旧。
- 预览从首段所在行延伸到末段所在行，匹配相隔较远时自动包含中间全部行。
- 新版搜索统一读写独立的普通表 `message_search_cache`，不扫描消息 JSON，并移除 Jieba 查询与词典资源。旧名 `message_fts` 保留为空的 `simple` FTS5 兼容表，旧版会忽略新缓存表，导回旧版后可手动重建旧索引。
- 新版打开数据库时若发现旧表存在条目，会先清空旧表，再与页面手动重建共用同一实现，从原始会话及消息记录全量重建新缓存，两个缓存表的旧内容都不会作为重建来源。
- “按照模型…”内提供“现有的模型”、“已被删除的模型”、“手动编辑的消息”三个选项。
- “按照附件…”可分别查找附件仍存在或本地附件已被删除的消息。
- 侧栏入口与搜索页标题统一复用“搜索消息”文案。
- 消息搜索在标题同一行显示“xx个结果”。
- 搜索结果改为每页 20 条，超过一页时在搜索框下方提供首页、上一页、页码输入、下一页和末页控件。

- 若翻译尚未完成时删除翻译结果，会先取消正在进行的翻译任务，再清除翻译内容。
- 删除“使用 App 风格指示器”开关，并永久禁用该样式，并删除兔子动画资源。加载状态恢复使用 RikkaHub 1.x 的无底板 Material 3 `LoadingIndicator`。
- DeepSeek 余额读取 `balance_infos` 中的 CNY 与 USD 总余额，并按 `x.xxCNY+x.xxUSD` 显示。
- 创建聊天分支时继承原会话文件夹；新聊天跟随当前所选文件夹。

- Android 12 及以上会读取设备物理屏幕底角半径：聊天主输入框底部不是直角时四个角都随屏幕边缘适配（回退 20dp）；输入法弹出使底部贴合为直角时，顶部两个角固定为 20dp。

- 全部通过 `LocalToaster` 触发的错误提示统一改为可滚动、可选择并可一键复制全文的弹窗；成功、警告及普通短提示统一改用 Android 系统 Toast，不再渲染应用顶部的彩色自定义浮层。打开链接、写入剪贴板和聊天图片导出等原本直接使用错误 Toast 的路径也接入该弹窗。
- SAF 文档提供器顶层改为 `data` 与 `workspaces`，分别暴露应用数据目录及按工作区组织的文件。
- 整个项目、Gradle Daemon toolchain、CI 与本地构建文档统一使用 JDK 21；各 Android 模块的 Java source/target compatibility 也统一为 21。
- 清理各网络服务对新版 OkHttp 非空响应体的冗余安全调用、密封类型 `when` 的多余 `else`，并移除低于项目最低 API 26 的废弃 Locale 兼容分支；仍有实际用途的旧 TTS 回调与消息序列化迁移类型继续保留，并仅在对应兼容代码中抑制弃用警告。
- V3 设置迁移不再于全新安装时写入空助手数组；首次安装、迁移异常或损坏设置产生空助手列表时也会自动补回默认助手，当前助手读取另有独立兜底，避免主界面与安全模式在启动阶段循环闪退。
- 修复切换助手后，在空白聊天页发送的第一条消息偶尔被写入上一个助手的问题。
- 删除聊天时同步清理其活跃内存会话；后台标题与聊天建议生成返回时只更新数据库中仍然存在的会话，避免已删除聊天被延迟持久化或迟到的后台结果重新插入。
- 会话持久化统一以最新内存状态为准：非生成状态更新时排队保存，进入后台时补存所有空闲会话；流式生成期间每秒保存一次，并在生成成功、手动取消或网络异常时于不可取消的终结阶段整理和强制提交最终状态；各会话的数据库写入串行化，避免旧快照覆盖标题、建议或消息；无内容的临时助手消息及重试候选分支会在失败或取消时删除并切回原回复，已有部分输出继续保留。
- 更新会话时按节点 ID 比较数据库实体与当前消息树，只删除已移除节点并写入新增或变化节点，不再全删全插全部消息节点。
