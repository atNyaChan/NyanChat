## 聊天与消息

### 助手切换

- 修复切换助手后，在空白聊天页发送的第一条消息偶尔被写入上一个助手的问题。
- 修复方式为在创建新会话时明确使用当前助手，避免异步状态更新期间读取到旧助手。
- 该问题触发概率较低，仍需在日常使用中继续观察。

### 字符及生成统计

- 用户消息的操作按钮行左侧显示字符数。
- 助手消息统计包含正文和思考过程的字符数。
- 一个 Unicode 字符按一个字符计算，中文汉字计为一个字符。
- 流式回复期间实时更新：
  - 字符数
  - 已用时间
  - 字符/秒
- 助手统计默认折叠为一行，显示输入、输出、缓存 token、时间及可能的费用，数字采用 `1.2K` 一类的缩写。
- 点击整块助手统计后展开为两行：
  - 第一行：精确字符数、时间、字符/秒。
  - 第二行：精确输入量、输出量、token/秒及可能的费用。
- 再次点击整块统计可恢复单行摘要。
- 用户消息的字符统计改为与助手统计一致的浅灰色样式。
- 用户消息和思考块的字符统计默认缩写；点击图标和文字组成的整个区域可显示完整数字，并扩大点击反馈范围。若少于 `1000`（即无需缩写）则不启用点击交互。
- 手动编辑且没有生成用量的助手消息只显示字符数。

### 编辑助手消息中的思考

- 编辑助手消息时，将 `Reasoning` 内容重新插入输入框并表示为 `<think>...</think>`。
- 保存编辑后的助手消息时，将 `<think>` 标签重新解析为独立思考块。
- 支持一条编辑文本中出现多个 `<think>` 块。

### 思考块

- 增加“复制思考过程”按钮，复制内容为 Markdown 原文。
- 思考完成并展开思考块后，顶部显示思考字符数及字符图标。
- 思考字符数同样默认缩写，点击字符图标或文字后显示完整数字。
- 思考字符数和复制按钮仅在思考完成且思考块展开时显示，折叠状态不显示。

### 空白消息

- 允许发送仅包含空格等空白字符的消息。
- 同步调整了输入校验、消息 UI 判断及发送给模型前的消息过滤。
- 真正的空字符串仍不能作为单独消息发送。
- 纯空白用户消息使用不可见占位符维持正常气泡行高；该占位符仅用于显示，不改变保存或发送的原始内容。

## 模型价格

- 每个提供商的每个模型均可选中“设置价格”。
- 支持填写以下价格，单位为美元/百万 token：
  - 输入
  - 输出
  - 缓存读取
  - 缓存写入
- 价格设置默认关闭，旧模型数据因字段具有默认值而保持兼容。
- 未出现缓存读取时，费用计算为：

  ```text
  输入价格 × 输入 token + 输出价格 × 输出 token
  ```

- 出现缓存读取时，不使用普通输入价格，费用计算为：

  ```text
  缓存写入价格 ×（输入 token - 缓存读取 token）
  + 缓存读取价格 × 缓存读取 token
  + 输出价格 × 输出 token
  ```

- 最终结果除以 `1,000,000`，并显示在助手消息统计末尾。

  - 阶跃星辰
  - 腾讯混元
  - 随想 AI 网关
  - AckAI

- 阶跃星辰 TTS 属于独立的语音提供商配置，本次没有删除。

## 备份与恢复

- 数据设置中的入口名称改为“备份与恢复”。
- 描述改为“备份或覆盖还原整个RikkaHub”。
- “聊天记录存储”改为“聊天文件存储”。
- 备份或导入进行期间：
  - 禁用页面左上角返回按钮。
  - 拦截 Android 系统返回操作。
- 本地、WebDAV、S3 的覆盖还原操作均增加确认弹窗。用户必须在提示现有配置和数据会被覆盖后点击“好”，才会进入文件选择或开始还原。
- ChatBox、Cherry Studio 等合并式导入不属于覆盖还原，因此不显示覆盖警告。
- 本地完整备份和还原固定包含数据库与文件，不再受 WebDAV 备份项目勾选状态影响。
- 导入完整备份后扫描消息数据库，将图片记录中的旧绝对 `file://` 路径按文件名改写为当前安装 `upload` 目录的路径。

## 统计页

- 聊天热力图从实际首次使用日期附近开始绘制，不再保留大量无数据区域。
- 最左侧保留一个星期的空白，便于观察起始边界。

## Web 服务器与 mDNS

- 地址区域只保留一个“网址”项目。
- 展示手机当前可用的全部局域网 IPv4 地址，每行一个。
- 不显示 `localhost`、`127.0.0.1` 或 IPv6 地址。
- 复制网址功能会复制当前展示的有效地址。
- Web 服务器启动后注册 mDNS，可通过对应的 `.local` 地址访问。
- 端口和密码输入框字号适当缩小，并使用正常字重，避免视觉上过大或过粗。

## 设置页与默认值

- 请求日志默认开启，并移动到“模型与服务”分组末尾。
- “关于”分组只保留“关于”入口。
- 删除设置页中的赞助、分享、使用文档入口。
- 删除“关于”入口右侧的 QQ 和 Discord 链接。
- 常规偏好默认值调整：
  - 消息导航按钮默认关闭。
  - 自动滚动默认关闭。
  - 用户头像默认不显示。
  - 模型名称默认不显示。
- 删除“使用 App 风格指示器”开关，并永久启用该样式。
- 新建助手的内置工具默认全部关闭。

## 兼容性说明

- 模型价格是带默认值的可选字段，旧备份导入本版本时无需包含该字段。
- 本版本导出的数据包含新字段。宽松解析未知字段的官方版本通常可以读取，但在官方 APK 上的实际导入结果仍应以测试为准。
- 默认提供商调整只影响尚未产生用户设置的新安装，不会主动清除已有数据。
